단계별 실행

앱 등록 → 초기 복사 → CDC → 쓰기 정지 → Cloud SQL 전환 → 앱 재개

  1. 1. 앱 등록프록시 alias 생성
  2. 2. 준비계획·사전 검사
  3. 3. 복사모의 CDC 시작
  4. 4. 쓰기 정지정지·최종 복제 확인
  5. 5. 전환승격·프록시 경로 변경
  6. 6. 재개대상에서 주문 쓰기

처음이면 ‘전체 시연’을 누르십시오. 각 단계를 직접 실행할 수도 있습니다.

대상 쓰기를 시작하면 역방향 CDC 없이 원본으로 복귀할 수 없습니다. 전체 실행은 Cloud SQL에서 운영을 끝냅니다.
