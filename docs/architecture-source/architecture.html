코드담당 작업
api.py · service.pyBearer 인증, 등록한 리소스 참조 검사, revision 검사, 명령 접수와 진행 조건 판정.
store.pyDynamoDB에 명령·상태·멱등 키·실행 의도·프록시 경로 저장. 조건부 트랜잭션으로 접수하고 중복 요청은 최초 결과 반환.
worker.pyDynamoDB 소유자 잠금으로 한 실행기만 허용. 복사·정지·전환·재개·복귀 명령을 실행.
postgres.pypublication·subscription, barrier, writer 차단, 데이터·sequence 대조, PgBouncer 설정과 관리 명령.
config_file.py설정 파일 UID·GID·mode·확장 속성 보존. 확장 ACL·외부 변경·보존 불가 시 교체 거절.
control.py신뢰한 오케스트레이터의 정지·재개 기록 SDK. 실제 앱 제어 채널은 별도 구현.
runtime.pyECS 설정, PgBouncer 시작·복원, API·Worker 실행.
dms.pyDMS SDK 호출, 실행 기록, 연결 검사·복제 시작 명령.
config.py · models.py등록한 리소스·업무 범위와 요청 형식 정의. Secret 값은 환경 변수로 주입.

Worker는 PgBouncer 설정 디렉터리를 공유해야 합니다. alias가 직접 정의된 파일을 등록하고 경로 값만 수정한 뒤 원자적으로 교체·RELOAD합니다. include로 읽는 alias 파일도 등록할 수 있습니다. 원격 PgBouncer의 경로만 API에 전달해서 배포하는 구조는 아닙니다.
