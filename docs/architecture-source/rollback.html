상태복귀 조건과 중단 위치
대상 쓰기 전원본이 기준 DB입니다. 대상 writer 차단과 쓰기 허용 의도가 없다는 영속 근거가 있으면 대상 장애 중에도 원본·프록시를 검사해 복귀합니다. 원본에서 이 계획의 정방향 복제를 정리하고 원본 schema·데이터만 검증합니다. 대상 재연결 후 FINALIZE합니다.
대상 쓰기 후같은 transitionId로 업무를 다시 정지합니다. 최종 역복제·데이터·sequence 검증이 끝나야 ROLLBACK을 허용합니다. 검증 실패 시 원본 경로로 넘기지 않습니다.
역복제 미준비BEFORE_TARGET_WRITE 모드에서 대상 쓰기를 연 뒤에는 빠른 원본 복귀를 제공하지 않습니다. 별도 데이터 복구 계획이 필요합니다.
원본 복귀 완료RESUME SOURCE 후 오케스트레이터가 앱 업무를 재개합니다. 해당 전환은 닫습니다. 다시 이전하려면 정리 후 새 계획을 만듭니다.

직접 복귀 도중 중단되면 RECONCILE이 원본 schema·snapshot과 송신 복제 정리 기록을 대조합니다. 불완전한 대상과 다시 비교하지 않습니다. 대상 쓰기를 허용한 적이 있거나 원본·프록시·정지 근거가 불명이면 이 경로를 사용하지 않습니다.
