5. 지원 범위와 검증 상태

  • 지원 프로필: postgres-logical-pgbouncer-v1. PostgreSQL 18, transaction pooling, 동일한 빈 대상 schema, PK와 DEFAULT replica identity가 있는 일반 table이 필요합니다.
  • 별도 준비: DB·계정·schema·네트워크·Secret·PgBouncer 배치. 이 코드가 인프라를 생성하지는 않습니다.
  • 지원 밖: RDS·Cloud SQL 권한 모델, MySQL, Redis, DDL 이전, RLS·partition·사용자 trigger·large object·2PC.
  • 운영 전 추가 검증: 큰 DB의 전체 digest 검사 시간, 쓰기 정지 시간, WAL 보관량, 실제 네트워크 장애, PgBouncer·실행기의 고가용성.

로컬 검증 기록에 초기 검사와 추가 회귀 검사 결과를 기록했습니다. 설정 보존·관측 실패·대상 장애·직접 복귀 중단·LSN·상태 경합을 보강했습니다. 상세 내용은 장애 경로 검토와 수정에 있습니다. 클라우드 운영 검증 결과는 아닙니다.
